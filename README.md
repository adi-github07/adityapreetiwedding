# Aditya & Preeti — Wedding Invitation

A free, single-page wedding invitation website.

## Included
- Responsive mobile-first design
- Wedding countdown
- Haldi, Mehendi, Sangeet and Wedding schedule
- Google Calendar button
- Google Maps button
- Family section
- No paid assets or backend required

## Free hosting
Upload `index.html` to a new GitHub repository and deploy it with Netlify.
You can also drag the folder into Netlify's manual deploy area.

## To customize later
Edit `index.html` and replace:
- TBD venues
- Groom's family details
- Contact numbers
- Photos/gallery
- Music
- Hashtag

The Google Calendar event currently assumes a 2-hour wedding duration; change the `end` value in the script if needed.
